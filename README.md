# 🧁 Fran's Brigaderie

Site oficial da confeitaria artesanal **Fran's Brigaderie**, desenvolvido com cardápio dinâmico integrado ao Supabase, carrinho de compras, pagamentos via Pix e painel administrativo.

## 🚀 Tecnologias Utilizadas
- HTML5, CSS3 e JavaScript
- Supabase (Banco de dados em nuvem)
